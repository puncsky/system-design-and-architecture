# `.pm` — book board

Public planning board for *System Design and Architecture*: new and improved chapters, bilingual (en / zh-CN) parity, and reach/build health.

- Conventions — pillars B1/B2/B3, hierarchy, sizing rule, closing tasks, templates — live canonically in [`.agents/skills/pm/SKILL.md`](../.agents/skills/pm/SKILL.md).
- `/pm-brainstorm <topic>` proposes work (text only); `/pm` is the **only** command that writes here; `/loopx <wN>` drains a workstream.
- Hard constraints: [`DO_NOT_DO.md`](./DO_NOT_DO.md).
- Layout: `wN/` worker queues → `wN/NNN.md` inbox notes (≤ ~1h) and `wN/mN/` milestones (> ~1h) → `wN/mN/tNNN.md` tasks. Completed work moves under `done/`.

This board is public — write everything in it for readers and contributors.
